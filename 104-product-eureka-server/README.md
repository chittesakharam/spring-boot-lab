# Task 104-A: Eureka Server - Product Monitoring

## Overview
A Spring Boot Eureka Server that provides service discovery for the
Product Service monitoring application.

## Technologies
- Java
- Spring Boot
- Spring Cloud Netflix Eureka Server
- Maven

## Configuration
- Enable Eureka Server.
- Run on port 8761.
- Register the Product Service with Eureka.

## Eureka Dashboard
http://localhost:8761

## Registered Service
- PRODUCT-SERVICE

## Key Class
- EurekaServerApplication

## Learning Objectives
- Configure Eureka Server.
- Register microservices.
- Understand service discovery.
