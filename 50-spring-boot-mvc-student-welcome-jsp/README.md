# Task 50 - Student Welcome Message using Model and JSP

## 📌 Objective

Create a Spring Boot MVC application that passes a message from the Controller to a JSP page using Spring MVC Model.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create a `/student` URL.
- Pass a message from Controller to JSP using `Model`.
- Use `model.addAttribute()`.
- Display the message using `${message}`.
- Do not use JSTL tags.

## 🌐 URL

```text
http://localhost:8080/student
