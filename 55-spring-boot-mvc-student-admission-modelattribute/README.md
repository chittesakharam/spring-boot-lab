# Task 55 - Student Admission Form using @ModelAttribute

## 📌 Objective

Create a Spring Boot MVC application with a Student Admission Form and display the submitted student details on another JSP page.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create a `Student` class.
- Create an admission form using `student.jsp`.
- Accept student details through an HTML form.
- Use `@ModelAttribute` in the Controller.
- Display submitted details in `studentResult.jsp`.

## 👨‍🎓 Student Fields

- Student ID
- Student Name
- Course
- Mobile Number

## 📂 Expected Files

```text
Student.java
StudentController.java
student.jsp
studentResult.jsp
