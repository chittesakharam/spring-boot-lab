# Task 106-A: Product Review Eureka Server

## Overview
A Spring Boot Eureka Server that provides service discovery for the
Product Service and Product Service Client.

## Technologies
- Java
- Spring Boot
- Spring Cloud Netflix Eureka Server
- Maven

## Configuration
- Enable Eureka Server using @EnableEurekaServer.
- Run on port 8761.
- Register Product Service and Product Service Client with Eureka.

## Eureka Dashboard
http://localhost:8761

## Registered Services
- PRODUCT-SERVICE
- PRODUCT-SERVICE-CLIENT

## Key Class
- EurekaServerApplication

## Learning Objectives
- Configure Eureka Server.
- Register microservices.
- Understand service discovery.
