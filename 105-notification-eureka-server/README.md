# Task 105-A: Eureka Server - Notification Monitoring

## Overview
A Spring Boot Eureka Server that provides service discovery for the
Notification Service monitoring application.

## Technologies
- Java
- Spring Boot
- Spring Cloud Netflix Eureka Server
- Maven

## Configuration
- Enable Eureka Server.
- Run on port 8761.
- Register the Notification Service with Eureka.

## Eureka Dashboard
http://localhost:8761

## Registered Service
- NOTIFICATION-SERVICE

## Key Class
- EurekaServerApplication

## Learning Objectives
- Configure Eureka Server.
- Register microservices.
- Understand service discovery.
