# Task 53 - Employee Details using Model and JSP

## 📌 Objective

Create a Spring Boot MVC application that passes multiple employee details from the Controller to a JSP page using Spring MVC Model.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create `/employee` URL.
- Pass multiple employee details using `Model`.
- Use `model.addAttribute()`.
- Display values using JSP Expression Language.
- Do not use JSTL tags.

## 🌐 URL

```text
http://localhost:8080/employee
