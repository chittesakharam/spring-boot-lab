# Courier Consumer

## 🎯 Objective

Develop a Spring Boot REST application that communicates with the **Courier Producer** application using `RestTemplate`.

The Consumer receives the courier status message from the Producer and returns the same message to the client.

---

## 🛠️ Technologies

- Java
- Spring Boot
- Spring Web
- REST API
- RestTemplate
- Maven
- Postman

---

## 📌 Application Details

| Property | Value |
|---|---|
| Project Name | CourierConsumer |
| Application Type | Consumer |
| Port | 8082 |
| Communication | RestTemplate |
| Producer Port | 8081 |
