# Spring Boot Lab 🚀

A structured collection of Spring Boot examples, real-world projects, and interview-focused implementations covering backend development from basics to advanced.

## 🎯 Objectives
- Learn Spring Boot through hands-on coding
- Build RESTful APIs
- Practice Spring MVC and Spring Data JPA
- Follow clean code and best practices
- Prepare for Java Full Stack interviews

## 🛠️ Tech Stack
- Java 17+
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

- [ ] Spring Boot Basics
