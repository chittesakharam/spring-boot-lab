# Courier Producer

## 🎯 Objective

Develop a Spring Boot REST API that provides a courier status message.

This application works as the **Producer** and exposes an API that can be consumed by another Spring Boot application using `RestTemplate`.

---

## 🛠️ Technologies

- Java
- Spring Boot
- Spring Web
- REST API
- Maven
- Postman
