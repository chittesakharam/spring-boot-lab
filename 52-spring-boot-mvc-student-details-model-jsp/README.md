# Task 52 - Student Details using Model and JSP

## 📌 Objective

Create a Spring Boot MVC application that passes hardcoded student details from the Controller to a JSP page using Spring MVC Model.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create `/student` URL.
- Pass student details from Controller to JSP.
- Use `model.addAttribute()`.
- Display values using JSP Expression Language.
- Do not use JSTL tags.

## 🌐 URL

```text
http://localhost:8080/student
