# Task 54 - Product Details using Map and JSP

## 📌 Objective

Create a Spring Boot MVC application that stores hardcoded product details in a Map and sends the data to a JSP page using Spring MVC Model.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create `/product` URL.
- Store product details in a `Map`.
- Use `model.addAllAttributes(map)`.
- Display values using JSP Expression Language.
- Do not use JSTL tags.

## 🌐 URL

```text
http://localhost:8080/product
