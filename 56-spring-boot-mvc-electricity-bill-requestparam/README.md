# Task 56 - Electricity Bill Calculator using @RequestParam

## 📌 Objective

Create a Spring Boot MVC application that calculates an electricity bill based on the number of units consumed.

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- JSP
- Maven
- Apache Tomcat

## 🎯 Requirements

- Create an electricity bill form using `bill.jsp`.
- Accept Customer Name and Units Consumed.
- Use `@RequestParam` to receive form values.
- Calculate the total bill in the Controller.
- Display the result in `billResult.jsp`.

## 📋 Inputs

- Customer Name
- Units Consumed
