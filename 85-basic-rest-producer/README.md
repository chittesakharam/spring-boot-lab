# Basic REST Producer

## 🎯 Objective

Create a simple Spring Boot REST Producer application that provides a REST API and returns a message.

This application will be consumed by a separate REST Consumer application.

## 🛠️ Technologies

- Java
- Spring Boot
- Spring Web
- REST API
- Maven

## 📌 Requirements

Create a REST Producer application.

Create the following endpoint:

| URL | Method | Response |
|---|---|---|
| `/producer/message` | GET | Hello from REST Producer |

## 🔗 Producer API

```text
GET /producer/message
