# Basic REST Consumer

## 🎯 Objective

Create a Spring Boot REST Consumer application that calls the REST Producer using `RestTemplate`.

The Consumer should receive the Producer message and print it in the console.

## 🛠️ Technologies

- Java
- Spring Boot
- Spring Web
- REST API
- RestTemplate
- Maven

## 📌 Requirements

Create a REST Consumer application.

The Consumer should call:

```text
http://localhost:8081/producer/message
